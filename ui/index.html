Assistant

The assistant runs on Claude. It needs an Anthropic API key, kept in the Windows Credential Manager.

When you ask it something, the mail it reads to answer is sent to the endpoint below.

Add a Gmail account

Unibox signs in with an app password, not your normal password. It is kept in the Windows Credential Manager on this PC.

Create one at myaccount.google.com/apppasswords (the account needs 2-Step Verification on).

Subscriptions

Doctor

What Unibox is connected to, what it is doing, and what it keeps on this PC.

Activity

Commands, sizes and timings since Unibox started. The mail itself is never recorded here, and nothing is kept after you close the app.
