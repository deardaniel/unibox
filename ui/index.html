Unibox signs in with an app password, not your normal password. It is kept in the Windows Credential Manager on this PC.

Keyboard shortcuts

j k or ↓ ↑Next / previous conversation
o or EnterOpen conversation now
Shift+Enter or Ctrl+clickOpen conversation in its own window
EscClear the selection
n pNext / previous message in a conversation
eArchive
zUndo the last archive, read/unread or star
sStar or unstar
Shift+i / Shift+uMark read / unread
xSelect conversation (actions then apply to all selected)
* then a / nSelect all / none
rReply (opens the conversation in Gmail)
/Search
g then iBack to all inboxes, clearing any search
1–9Show only that account (0 for all)
